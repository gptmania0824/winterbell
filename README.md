# Winter Bell

ブラウザだけで遊べる、Winterbells系のオリジナル作品です。

## 遊び方

- マウスを左右に動かして白いウサギを誘導します。
- 落下中に鐘へ着地すると、鐘が次のジャンプ台になります。
- 高い鐘ほどスコアを伸ばせるよう、連続プレイ向けに難易度が上がります。
- 落下するとゲームオーバーです。
- 最高スコアはブラウザの localStorage に保存します。

## 技術

外部ライブラリ・外部画像・外部音源を使わず、HTML / CSS / JavaScript / Canvasだけで実装しています。

元作品のゲーム性を参考にしていますが、画像・音源・コードはコピーしていません。
